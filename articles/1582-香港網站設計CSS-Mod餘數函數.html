CSS Mod餘數函數是CSS Values and Units Module Level 4規範中引入的一個數學函數，它計算兩個數值之間的模運算（modulo）結果。mod()函數的語法為mod(valueA, valueB)，返回valueA除以valueB的餘數。與傳統的JavaScript模運算不同，CSS的mod()函數始終返回與除數相同符號的結果，這使得它在處理循環模式和週期性設計時特別有用。在2026年的香港網站設計領域，mod()函數為開發者提供了在純CSS中實現循環計算的能力，打開了響應式設計的新大門。
